SarkitCloud

Connect any device.
Watch the data arrive.

Sarkited collects readings from ESP32, Arduino, Raspberry Pi, or anything that can make an HTTP request — stores them, charts them, and pushes every update to your screen the instant it lands. Up to 20 fields per channel, no daily limits.

Get your device sending data in 2 minutes

  1. Create a channel above and copy its Write API Key from the channel page.
  2. Open Arduino IDE with ESP32 board support installed (WiFi.h and HTTPClient.h are built in).
  3. Paste the sketch below. Change only WRITE_API_KEY and SERVER_URL — nothing else needs to change.
  4. Flash it to your ESP32 / ESP8266 board. It posts a reading every 15 seconds using plain HTTP.
  5. Open the channel page here and watch live values and charts update in real time.
